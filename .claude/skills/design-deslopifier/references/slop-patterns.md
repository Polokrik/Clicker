# Slop Pattern Library

Use this library as a diagnostic aid, not as a scoring system. A pattern is a problem only when it is unjustified in the current context.

## Card monoculture

**Signal:** Navigation, metrics, actions, copy, and media all use similar rounded cards.

**Impact:** Unrelated information receives equal visual weight and the page loses hierarchy.

**Corrections:** Remove outer containers, use spacing and alignment for grouping, reserve bordered surfaces for interaction or meaningful containment.

## Nested surfaces

**Signal:** Cards contain panels that contain smaller cards.

**Impact:** The user decodes containers instead of content.

**Corrections:** Flatten the hierarchy, promote important content, keep only the surface that communicates a real parent-child relationship.

## Dashboard by default

**Signal:** Charts, counters, progress bars, and status blocks appear even when the task does not require monitoring.

**Impact:** Decorative data adds cognitive load and can hide the actual workflow.

**Corrections:** Start from the user's task, remove unsupported metrics, replace monitoring components with the relevant action or content.

## Equal-weight grid

**Signal:** Several same-sized modules compete for attention.

**Impact:** No focal point or reading order emerges.

**Corrections:** Vary scale and placement according to priority, use one dominant area, demote secondary information.

## Predictable hero formula

**Signal:** Centered label, oversized heading, paragraph, two buttons, gradient background, and floating mockup.

**Impact:** The design could represent almost any product.

**Corrections:** Build the hero around the product's real action, content, object, image, or proof. Remove duplicated explanation.

## Decorative density

**Signal:** Badges, separators, icons, helper text, labels, and small visuals accumulate around simple content.

**Impact:** The interface appears busy without becoming more informative.

**Corrections:** Remove elements that do not change meaning, action, state, or navigation.

## Badge and pill overflow

**Signal:** Many labels are rendered as rounded pills regardless of function.

**Impact:** Status, category, filter, and decoration become indistinguishable.

**Corrections:** Reserve pills for compact selectable filters or meaningful status. Use plain text for metadata.

## Gradient-as-identity

**Signal:** A generic blue, violet, or pink gradient carries most of the visual personality.

**Impact:** The design lacks product-specific character.

**Corrections:** Define palette behavior, imagery, geometry, and typography. Use gradients only when they support the concept.

## Unsupported glass effects

**Signal:** Blurred translucent panels appear without spatial or thematic reason.

**Impact:** Legibility decreases and the interface follows a trend rather than a purpose.

**Corrections:** Use solid surfaces, clear layering, and contrast. Keep translucency only when actual depth or overlay context warrants it.

## Universal large radius

**Signal:** Every card, button, input, image, and modal uses a large similar radius.

**Impact:** Component roles blur and the visual language feels automatic.

**Corrections:** Define a restrained radius scale and use geometry to indicate role.

## Shadow everywhere

**Signal:** Every surface appears elevated.

**Impact:** Layering becomes meaningless and the page feels soft and muddy.

**Corrections:** Use borders, contrast, or spacing for most grouping. Reserve elevation for overlays and objects that truly sit above another surface.

## Icon confetti

**Signal:** Icons appear beside almost every heading, metric, and label.

**Impact:** Icons become decoration rather than recognition aids.

**Corrections:** Keep icons for actions, navigation, status, or rapid recognition. Remove icons that repeat nearby text.

## Placeholder illustration

**Signal:** A random abstract illustration fills an empty region.

**Impact:** The visual does not explain, prove, or embody the product.

**Corrections:** Use product imagery, photography, diagrams, data, objects, or expressive typography with a clear role.

## Image-in-a-box

**Signal:** A strong image is inserted inside an otherwise unchanged card template.

**Impact:** The image decorates the layout but does not shape it.

**Corrections:** Let the image determine crop, scale, overlap, contrast, spacing, and text placement.

## Surface-only restyling

**Signal:** Fonts, colors, and texture change while composition remains generic.

**Impact:** The new style feels pasted onto the same template.

**Corrections:** Revisit hierarchy, proportions, grouping, and focal point before applying polish.

## Style collage

**Signal:** Several fashionable aesthetics are combined without one central idea.

**Impact:** The result is visually loud but incoherent.

**Corrections:** Choose one concept and define what must be excluded.

## Default typography

**Signal:** Neutral system typography is used without considering product character or reading behavior.

**Impact:** The result lacks voice or has weak hierarchy.

**Corrections:** Choose typography for the context. Define display, body, utility, scale, line length, and weight behavior.

## Giant-heading compensation

**Signal:** A very large heading attempts to create impact on an otherwise weak composition.

**Impact:** Space is consumed without improving meaning.

**Corrections:** Improve the visual idea and composition; size the heading according to content and viewport.

## Centered-text overuse

**Signal:** Dense or actionable content is centered.

**Impact:** Scanning and comparison become harder.

**Corrections:** Center only short, expressive content. Left-align text that must be read or used.

## Generic marketing copy

**Signal:** Phrases such as "unlock the power", "seamless experience", or "next-generation solution" replace concrete value.

**Impact:** The interface becomes interchangeable and verbose.

**Corrections:** Name the task, outcome, object, or evidence directly.

## Redundant explanation

**Signal:** Subtitle, helper text, and body copy repeat the title or button.

**Impact:** The interface feels generated and slows comprehension.

**Corrections:** Keep the shortest line that contributes new information.

## Fake specificity

**Signal:** Unsupported metrics, testimonials, activity, or progress are used to make a mockup look realistic.

**Impact:** The design misrepresents the product and distorts hierarchy.

**Corrections:** Use supplied data, label examples clearly, or design a truthful empty state.

## Mobile stacking only

**Signal:** Desktop columns simply stack on small screens.

**Impact:** Priority, interaction order, and density are not reconsidered.

**Corrections:** Reorder by task, simplify secondary content, adapt controls, and redesign the first viewport for touch.

## Motion as decoration

**Signal:** Floating, pulsing, parallax, or continuous motion has no state or narrative purpose.

**Impact:** Attention is pulled away from the task and accessibility may suffer.

**Corrections:** Tie motion to hierarchy, feedback, navigation, or causality. Support reduced motion.
